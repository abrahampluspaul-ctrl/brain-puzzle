# Brain Sparks 🚀

**Mind challenges for clever kids (ages 8–10)**

A fun, colorful collection of educational puzzles covering:

- 🍎 **Math Mysteries** – picture equations & number clues
- 🔤 **Word Scrambler** – un-scramble words with picture hints
- 🔍 **Logic Detective** – patterns, odd-one-out, sequences
- 🃏 **Memory Flip** – classic matching pairs
- 🤖 **Robot Coder** – program a robot with arrows to reach the star
- ⚙️ **Mechanics Lab** – gears, levers & pulleys (interactive!)
- 📚 **Lessons** – interactive experiments that teach the big ideas

## Features
- Three difficulty levels (Easy / Medium / Hard)
- Stars & streak tracking (saved in the browser)
- Sound effects (toggleable)
- Fully offline-capable Progressive Web App (PWA)
- Works great on phones and tablets

## How to install / play

### Option 1 – GitHub Pages (recommended)
1. Go to the repository **Settings → Pages**
2. Under “Source”, choose **Deploy from a branch** → `main` → `/ (root)`
3. After a minute you’ll get a link like:  
   `https://abrahampluspaul-ctrl.github.io/brain-puzzle/`
4. Open that link on a phone → browser menu → **Add to Home Screen** / **Install**

### Option 2 – Local
Just open `index.html` in any modern browser.

## Tech
- Pure HTML + CSS + vanilla JavaScript (no frameworks)
- Service Worker for offline use
- LocalStorage for progress

Made for curious kids who love puzzles 💡
